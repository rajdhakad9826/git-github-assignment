Git commands used during the assignment:

1. git init
=> Initializes a new Git repository in the current directory

2. git add <file>
=> Stages the specified file for the next commit

3. git commit -m "commit message"
=> Commits the staged changes with a message

4. git status
=> Displays the current status of the repository

5. git checkout -b <branch>
=> Creates a new branch and switches to it

6. git checkout <branch>
=> Switches to the specified branch

7. git log
=> Shows the commit history of the repository

8. git merge <branch>
=> Merges the specified branch into the current branch

9. git reset --soft HEAD~1
=> Unstages the last commit, keeping the changes in the working directory

10. git remote add origin <repository_url>
=> Adds a remote repository with the specified URL

11. git push -u origin <branch>
=> Pushes the local branch to the remote
